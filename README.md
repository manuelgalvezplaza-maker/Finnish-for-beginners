# Finnish-for-beginners

Aplicación para preparar un examen de finés con vocabulario, escritura, conjugación, números, horas, exámenes, repaso de errores, notas y puntuaciones.

## Archivos

- `index.html`: entrada web principal; contiene la aplicación completa.
- `Suomi15.html`: la misma aplicación con su nombre original.

La aplicación no requiere instalar paquetes ni cargar imágenes, fuentes o scripts externos. El visor de código de GitHub no ejecuta HTML: para usarla desde un móvil hace falta abrirla desde un sitio web estático. En este repositorio privado, la configuración de GitHub indica que Pages requiere cambiar el repositorio a público o actualizar el plan. Hacerlo público expondría todos los archivos del repositorio.

## Funciones

- Interfaz en español, inglés y alemán; el contenido finlandés se conserva en finés.
- Más de 750 registros de vocabulario, con traducciones al inglés y alemán.
- Repaso por capítulos y temas, incluidos los 12 meses, familia, países, idiomas, nacionalidades y una paleta amplia de colores.
- Práctica escrita y corrección con los errores resaltados.
- Conjugación afirmativa y negativa, tabla de referencia de los cinco tipos y ejercicios para completar paradigmas.
- Práctica de números en finés.
- Sección para decir y escribir la hora con 240 combinaciones, dos modos de ejercicio y una guía de ejemplos.
- Exámenes por capítulo o de todo el temario.
- Perfiles locales, puntuaciones por tema, repaso de fallos y apuntes.

## Progreso y privacidad

El progreso y las notas se guardan localmente en el navegador, separados por perfil. Para continuar en otro dispositivo, exporta el respaldo desde «Puntajes» e impórtalo en el otro navegador. El archivo de respaldo contiene datos de estudio personales; no lo subas al repositorio.
