# Finnish-for-beginners

Aplicación local para preparar un examen de finés con vocabulario, escritura, conjugación, números, simulacros, repaso de errores, notas y puntuaciones.

## Uso

Abre `Suomi15.html` en un navegador. La aplicación funciona como un único archivo HTML e incluye los datos del curso.

## Funciones

- Interfaz en español, inglés y alemán; el contenido finlandés se conserva en finés.
- Tarjetas de vocabulario y ejercicios de respuesta escrita.
- Tabla de referencia con afirmativo y negativo para los cinco tipos de verbo, más práctica de conjugación.
- Práctica para escribir números en finés.
- Exámenes de capítulos y simulacros generales.
- Perfiles locales, seguimiento de aciertos, repaso de fallos y apuntes.

## Progreso y privacidad

El progreso y las notas se guardan localmente en el navegador, separados por perfil. Para pasar el progreso a otro dispositivo, exporta e importa el respaldo desde la sección de puntuaciones. No subas el archivo de respaldo al repositorio: puede incluir datos personales de estudio.
